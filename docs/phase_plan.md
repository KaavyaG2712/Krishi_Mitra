# Review 3 delivery plan

## Phase 1 — Foundation and data readiness

Set up the repository safeguards, local PostgreSQL + pgvector service, FastAPI base, data registers, and local environment configuration. Catalogue the selected PlantVillage data and authoritative source documents. No model or raw data is committed to Git.

## Phase 2 — Core local services

Train and evaluate the 10-class MobileNetV2 baseline. Add PostgreSQL schema/migrations, document ingestion, PostgreSQL full-text retrieval, Python keyword rules, cited responses and API tests. The agronomy chat does not use embeddings or Gemini generation.

## Phase 3 — Review UI and integration

Build the React image-upload and cited local-advisor pages. Connect both to FastAPI, persist scans/conversations/citations, and test safe failure cases.

## Phase 4 — Demonstration evidence

Record model and retrieval metrics, run browser-to-database flows, capture screenshots, complete a clean-laptop local run, and prepare the review demonstration.
