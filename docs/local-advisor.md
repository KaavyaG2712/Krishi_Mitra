# Gemini agronomy advisor

`POST /api/v1/advisor/chat` accepts a question in English, Hindi, Tamil, Telugu, Bengali, Marathi, or Kannada. For retrieval, regional-language questions are translated to English; Gemini receives the original question and is instructed to answer in the selected language and native script. Retrieved ICAR/MANAGE text is optional supporting context, not the answer template or an exclusive knowledge source. The model is asked to answer the farmer's specific question, avoid copying passages, cite claims supported by retrieved sources, and still answer from its broader agronomy knowledge if retrieval finds nothing. Chat messages and voice playback retain the language used for that turn.

The site language selector translates visible page text on demand through `POST /api/v1/advisor/translate-ui`; successful translations are cached on the device. Each agronomy answer is generated by the configured `GEMINI_GENERATION_MODEL`. `GEMINI_API_KEY` is read by the backend from `backend/.env`; it must never be exposed in browser code. The same key supports UI/question translation and server-side speech transcription. If Gemini or the network is unavailable, page strings remain readable in their original language and the advisor reports a retryable error. AI translation and agricultural guidance should receive native-speaker review before formal publication.

The advisor is limited to agriculture and KrishiMitra project questions. It must not invent diagnoses, sources, local weather or laws, and it must not provide pesticide/fertilizer application quantities or spray schedules. Chemical use, severe crop damage and uncertain symptoms should be checked with the product label and local KVK/agricultural staff. Retrieved sources remain visible with the answer for verification.

Retrieval is a PostgreSQL full-text search used to find supporting passages. It does not generate the answer and its failure does not prevent Gemini from answering a genuine agriculture question. The included starter corpus is maintained by the project; a user does not need to upload documents to chat.
